An engineering team is deploying a customer support agent on the Anthropic Messages API. The workflow maintains a 25,000-token system prompt containing product documentation, followed by a dynamic multi-turn conversation. Latency on initial turns and API costs have grown substantially. What architectural change best addresses both issues?

CORRECT ANSWER: B · Applications & Integration

Prompt caching caches exact prefix tokens. By placing the static 25,000-token product documentation at the beginning with cache_control: {"type": "ephemeral"}, subsequent requests achieve a 90% cost reduction on cached read tokens and cut time-to-first-token (TTFT) by up to 85%.

Distractor Analysis: Option A breaks prefix alignment; Option C loses critical information without addressing root cause; Option D refers to deprecated APIs.
